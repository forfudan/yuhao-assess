# 命名規範

本倉庫的變量、類型、函數等命名儘量採用 [GujiCC](https://github.com/forfudan/GujiCC) 定義的大陸調和繁體漢字標註，除非必須使用英文的情况。命名時，应當具體、詳細，少用縮寫、俗稱。下表列出一些常用的術語的命名規範。其中：

- **標準名稱**爲本倉庫推薦使用的名稱。
- **其他别名**爲其他倉庫常見的别名、俗稱、簡稱。在本倉庫中，變量的命名不应當使用這些别名。
- **英文命名**爲本倉庫無法使用中文命名時的推薦英文名稱。
- **解釋**對某些術語進行了補充説明。

注意，這些命名規範只對變量、類型、函數等程式碼命名生效，對於文檔中的描述性文字、展示給用户的文字不受此限制，可以根據語境靈活使用各種名稱。

## 通用術語

| 標準名稱 | 其他别名 | 英文命名           | 解釋                                     |
| -------- | -------- | ------------------ | ---------------------------------------- |
| 原子狀態 | 原子     | atom               | 使用「原子狀態」而非「原子」，保證可讀性 |
| 字根     | 碼元     | root / zigen       |                                          |
| 通用規範 | 通規     | tonggui            |                                          |
| 常用國字 | 國字     | guozi              |                                          |
| 頻數     |          | Absolute Frequency | 出現次數(整數), "的" 出現 1000 次        |
| 頻率     |          | Relative Frequency | 出現比例(小數), "的" 佔 0.05（5%）       |
